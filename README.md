## Project Description

Calculator Master is a menu-driven Python calculator developed using Git and GitHub branching. The project demonstrates Python programming, Git branching, source code management, pull requests, merge operations, and version control practices.

## Branch Structure

The project uses the following feature branches:

- `addition_Tan` - Addition operation
- `subtraction_Tan` - Subtraction operation
- `multiplication_Tan` - Multiplication operation
- `division_Tan` - Division operation

All completed feature branches were merged into the `main` branch.

## Program Features

- Addition
- Subtraction
- Multiplication
- Division
- User input validation
- Invalid input handling
- Division-by-zero handling
- Menu-driven interface
- Continuous execution until the user selects Exit
